## Direction contract
THESIS: Everything is read on the two axes traffic engineers think in: distance and time. The portal is a time–space instrument, not a dashboard.
WORLD: Signal-ops / ATSPM worksheets and the time–space diagram. Cool neutral field (#F3F4F1 paper-grey, ink #14171A), hairline graticule, signal-state colours used only for signal and severity meaning (green #1F7A4D, amber #C98A00, red #B3261E), one live accent: conflict amber. Overpass (Highway Gothic lineage) for headings, Public Sans (USWDS) for UI, Overpass Mono tabular for every figure. Dark "LiDAR night" variant only inside the intersection 3D view.
FIRST VIEWPORT: Atlas opens on a real time–space diagram of NGSIM trajectories drawing in at 10 Hz beside the Lubbock network map; conflicts tick amber as they occur; 3 true KPIs set in mono.
VISITOR PATH: Atlas → Screening (ranked segments ↔ map) → Corridor straight-line diagram → Intersection lab (2D/3D, SSM, repair) → Methods → Platform → Ask.
SIGNATURE INTERACTION: a shared time/stationing cursor: scrubbing time on any diagram moves vehicles in plan, 3D and time–space together; scrubbing DFO on a corridor moves the map marker and every strip.
RISK: dense graphics can read as intimidating to non-specialists; acceptable for an expert audience, mitigated with plain-language captions.
