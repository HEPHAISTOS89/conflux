## Platform & Roadmap — iteration 1 (2026-10-17)
**Platform: living architecture diagram** (`src/components/arch/{model.ts,FlowDiagram.tsx,NodePanel.tsx}`). Two lanes: *Running now* (EventBridge rule → Lambda ingest → S3; EventBridge Scheduler → self-stopping EC2 → S3; S3 → Lambda API → API Gateway → Vercel; IAM and CloudWatch as bands; Bedrock "awaiting AWS verification · fallback active" and CloudFront "defined in CDK", dashed) and *Pilot design* (roadside LiDAR → edge unit → S3 pilot/ → conflict Lambda → API → SPAG dashboard, plus warning beacon and sensor health), all dashed and labelled Planned. Smooth cubic Béziers, colour per data type (public data amber, curated sage, API sky, metrics rose, analyst sand, planned neutral) in both themes, owner-requested direction gradient. One rAF loop moves comets with fading tails; rate and speed are log-scaled from real volume (CloudWatch invocations over 7 d, manifest records per source, run counts); a dash stream drifts on every running edge; nodes ring and breathe on arrival. Node state comes from data: last run failed → red; EC2 idle/grey (inferred from run records: it stops after each job); next trigger dates computed from the stack's cron expressions. "Backlog drains on recovery" replays the real event in the run records (trajectories job failed 07:11 UTC, succeeded 10 min later), and a labelled SIMULATION toggle takes any stage down locally. Every node opens a panel (role, service, live metrics with their source, sources and records, connections, configuration, cost); open node is in the URL (`?node=api`). Header readouts: stages up, last ingest, API p95, monthly cost estimate (derived from metrics × list prices, with methodology). Pauses when hidden/off-screen; reduced motion shows static coloured arrows with rate labels.
**Roadmap**: route-line board (Done 8 / In progress 2 / Prototype 2 / Planned 5): solid route where things run, dashed where they do not; each card has icon, one line, status chip, "Needs" for unfinished items and a link to the live page; vertical route on phones.
**Verified** in the browser at 1440/1024/390, light and dark, with the deployed AWS payload and local mode: comets moving, replay and simulation (queue → drain), node click/keyboard/Escape, deep link, reduced-motion path, no horizontal page scroll, console clean of page errors.
Critique 1 (creative director): short edges made labels collide → two-line value/unit labels, wider gaps; banner caused layout shift → permanent LIVE/SIMULATION/REPLAY status line; Done column too tall → link moved to an icon button; redundant status strip removed. Critique 2 (TransTech researcher): wanted provenance per number → every panel names its source (CloudWatch window, run id, manifest, stack); wanted cost basis → line-by-line estimate with prices. Clearly-better addition: shareable `?node=` deep link.
Scores (Platform / Roadmap): hierarchy 9/9, typography 9/9, icons 9/9, data clarity 9/9, technical accuracy 9/9, motion 9/9 (roadmap: static by design), a11y 9/9, performance 9/9, polish 9/9, wow/anticipated needs 9.5/9.

## Intersection lab — iteration 1 (2026-10-17)
GOAL.md §1 delivered on the real NGSIM vehicle tracks (no pedestrians in these files; the HUD and legend say so).

**3D (src/lib/lab/engine.ts, components/LidarView.tsx, components/lab/*)**
- Modes: orbit (damped, polar/distance limits), free-fly (WASD/arrows, Q/E, Shift ×3, drag-look; arrows no longer step time while flying), follow (chase cam on the heading; drag swings, wheel distance), top-down orthographic (north-up, true scale, drag pan, wheel zoom), sensor POV (pole head, drag-look, wheel FOV). `C` cycles.
- Animated presets named after real geometry: Approach lane, Conflict zone (severity-weighted centroid of conflict points, or the studied conflict), Stop line (stop bar estimated from queue heads: 95th-percentile stopped position, drawn in the scene), Sensor POV. `P` cycles. Reduced motion jumps.
- Fullscreen on the whole lab panel (button, `F`, Esc), pseudo-fullscreen fallback where the API is refused or pending (embedded browsers, iPhone); HUD, selection, clock and camera survive; resize via ResizeObserver.
- HUD: ID, class, movement, speed mph, heading ° (bearing from corridor north), accel ft/s², track confidence (kinematic-consistency score, MetricInfo), live constant-velocity TTC (two-circle footprint), pair PET from the trajectories, and a TTC profile sparkline with the 1.5 s SSAM line.
- Layers: point cloud / bodies, trails (3 s, all), 2 s constant-acceleration "projection", conflict zones (rings, brighter while active), sensor FOV cone (−25°…+15°, 80 m, blind radius ring). Persisted per viewer.
- Minimap (lanes, vehicles, camera wedge or ortho frame, click to move) + compass with heading readout.
- Near-miss moment: playback eases to 0.35× within ±0.6 s of the studied conflict (clock warp, chip in the transport), pulsing beacon + tag at the conflict point, linked framing on selection, "Replay from 3 angles" (chase A, chase B, overhead; `R`).
- Performance: all vehicle returns in one draw call (pose DataTexture + shader), bodies and picking instanced, render on demand, point size clamped, no rAF while hidden (engine + clock, dt clamped). Measured 120 fps steady (p99 frame 9.3 ms at dpr 2, 1024 px, playing). WebGL2 check → plan view + notice.

**Page**: PageHeader verdict (conflicts, critical, worst TTC, data completeness); Data-health strip (frame completeness, longest gap, position-jump tracks, high-confidence share, repaired tracks from the occlusion benchmark; Derived chip); timeline 0.25–4×, 10 Hz frame steps (`,` `.`), previous/next risk event (`[` `]`, buttons); Select filter with counts; MetricInfo on TTC/PET/DRAC (header split from the scroller so popovers are not clipped); exports: PNG of plan/3D/time–space (canvases only, source caption), CSV of filtered conflicts, CSV of spot speeds; approach spot-speed histogram (NB vs SB, 5 mph bins, 85th percentile, 65/100/150 ft line); `?` shortcut sheet (modal, focus in/out, works in fullscreen). Mobile overflow fixed (grid min-content from tables).

**Tests**: vitest, 17 unit tests on src/lib/lab/metrics.ts (bearing, kinAt, confidence, data health, spot speeds, histogram, percentile, CA projection, TTC, PET, stop line, near-miss warp, risk navigation, frame stepping).

**Critique → fixes**: CD: point sprites ballooned up close (clamped); compass read as a pencil (rose with N pointer); zones were blurry coins (rings); moment bar collided with layers (moved under presets); layers panel too heavy by default (collapsed). Researcher: confidence needed a definition (MetricInfo + docs); live TTC vs screened TTC disambiguated; PET marked n/a for following; "Derived/Simulated" provenance on health and sensor model; licence claim removed from header (footer owns it). Clearly-better: TTC profile sparkline in the HUD — the shape of the conflict, not just its minimum.

Scores (before → after): hierarchy 7→9, typography 8→9, icons 7→9, data clarity 7→9, technical accuracy 8→9, motion usefulness 6→9, 3D 6→9, accessibility 7→9, performance 7→9, polish 7→9, wow/anticipated needs 6→9.
